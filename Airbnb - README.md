# NYC Rent Price Predictor

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://cis-9660-will-apps.streamlit.app)

A Streamlit web application that estimates the rental prices **NYC AIR_BNB** using:

- webscraped information from AirBNB  
- XGB Linear Regression

## Project Overview

The goal of this project is to predict nightly prices for NYC Airbnb to help hosts set competitive pricing and understand pricing patterns.

## Setup Instructions

Install dependencies, and ensure that the relevant keys and websites are easily accessible.
For the dependencies you will see them present in the requirements.txt on this github.

## Usage Instructions

The website is designed to be two fold:
1. You can predict how much your Airbnb cost should be given the factors that go into pricing a property.
2. Analyse the average cost by bedrooms for each neighborhood to get a better understanding of the ecosystem.
